HOW IT WORKS

About Survivor War Room

Every recommendation this app makes is built from live, free public data — no paid AI model, no black box. This page explains exactly what's being pulled, in what order, and how it turns into a ranked list of picks.

Data sources

Everything below is fetched fresh, directly from your browser, each time you click "Pull live data" or "Refresh live data"
The Odds API PRIMARY ODDS
A multi-sportsbook consensus moneyline. The app requests head-to-head (h2h) American-odds prices from every book The Odds API reports for a matchup, averages them, and converts the average into an implied win probability. Because multiple books rarely agree exactly, averaging smooths out any single book's quirks or vig. This call goes through a private Netlify Function so the API key never reaches your browser.
api.the-odds-api.com/v4/sports/americanfootball_nfl/odds — proxied via /.netlify/functions/odds
ESPN Scoreboard & Odds FALLBACK ODDS
Used whenever The Odds API doesn't have a matchup yet (or is unreachable). ESPN's public scoreboard returns each week's matchups, kickoff times, unique event IDs, and — when posted — a single sportsbook's moneyline and point spread for the game.
site.api.espn.com/apis/site/v2/sports/football/nfl/scoreboard
ESPN Predictor (FPI) FALLBACK MODEL
ESPN's own Football Power Index-based pregame win projection. Sportsbooks don't post lines for games more than a couple of weeks out, but ESPN's predictor computes a projection for essentially any scheduled game on the calendar. This is the only source used for far-future weeks, and it's always labeled "ESPN Predictor" or "modeled" in the app so it's never confused with a real market line.
sports.core.api.espn.com/.../events/{id}/competitions/{id}/predictor
ESPN Game Summary (Injuries)
For each of the week's top candidates, the app pulls that specific game's injury report and keeps only quarterbacks, running backs, wide receivers, and tight ends whose status isn't "Probable" — the positions and designations most likely to swing a game's outcome.
site.api.espn.com/apis/site/v2/sports/football/nfl/summary?event={id}
Open-Meteo (Weather)
Hourly forecast — temperature, precipitation chance, and wind speed — for the home stadium's coordinates, matched to the closest hour to kickoff. Skipped entirely for the 12 NFL stadiums with a dome or fixed roof. Forecasts only exist inside roughly a 15-day window before kickoff; outside that window the app says so rather than guessing.
api.open-meteo.com/v1/forecast

How a win probability is chosen

For every team in every matchup, the app tries each source in order and stops at the first one that has real data
1. The Odds API consensus
→
2. ESPN moneyline
→
3. ESPN posted spread
→
4. ESPN Predictor (FPI)

Steps 1 and 2 both start from American moneyline odds and convert them to a probability, then remove the sportsbook's built-in vig by normalizing both teams' probabilities so they sum to exactly 100%:

impliedProb(moneyline) = moneyline < 0 ? -moneyline / (-moneyline + 100) : 100 / (moneyline + 100)
// then, with both teams' raw implied probabilities:
fairProb(team) = impliedProb(team) / (impliedProb(home) + impliedProb(away))

Step 3 applies when a moneyline hasn't been posted but a point spread has. A spread is converted to a probability with a standard logistic curve:

homeWinProb = 1 / (1 + 10-spread / 14)

Step 4 is used when nothing has been posted at all — most commonly for games several weeks in the future. ESPN's Predictor already returns a clean win-probability percentage per team, so it's used as-is.

Building the weekly recommendation list

  1. Pull that week's full matchup list from the season schedule.
  2. Resolve a win probability for every team in every matchup using the priority chain above.
  3. Remove any team already marked "used" in your tracker — a used team can never be recommended again.
  4. Sort every remaining team, across every game that week, by win probability — highest first — and keep the top 5.
  5. For each of those 5, attach injury notes, a weather read, and a future-outlook note (below).
  6. The single highest-probability team becomes the top recommendation (or the top two, for a double-pick week).

The "consider saving" future-outlook check

A high win probability this week doesn't automatically mean a team is the right pick this week — if that same team is an even bigger favorite three weeks from now, burning it early can cost you later. To catch this, every one of the week's top-5 candidates is checked against the rest of its own schedule:

  1. For each remaining week on that team's schedule, the app resolves a win probability the same way as above (real odds/spread first, ESPN Predictor as the fallback).
  2. The single best remaining week is kept.
  3. If that future week's probability is more than 5 percentage points higher than the current week's, the pick is flagged "Consider saving" with the specific week and opponent named.
  4. Otherwise, the app simply shows the team's best remaining spot for reference.

Every future-outlook number is labeled with its source (a real posted line, or "ESPN Predictor" / "modeled") so you always know whether you're looking at market data or a projection.

What this app doesn't do

  • No large language model, no AI-generated analysis, and no paid API calls are involved in scoring picks — every number above comes from a documented formula run in your own browser.
  • It doesn't optimize your entire season's pick sequence at once — the future-outlook check compares a team against its own future weeks, but it isn't a full season-long solver.
  • It doesn't account for game script, weather beyond kickoff-hour conditions, or breaking news between when you check and when you lock a pick — always double-check injury designations right before kickoff.
  • Your picks and used-team tracker are stored only in your own browser's local storage — nothing is sent to a server or shared with anyone else using the app.
This is a strategy aid built on free, publicly available sports data — it is not a guarantee of any outcome. Always verify injury designations and weather close to kickoff before locking a pick.
